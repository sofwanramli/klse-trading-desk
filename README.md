# KLSE Trading Desk

A shared view of a personal Bursa Malaysia screener: the day's BUY signals with trade plans (buy price, cut loss, TP1, TP2), tracked open trades, the swing watchlist, trade history and backtest results.

The page is `index.html`; the numbers are the JSON files in `data/`, replaced after each weekday screener run. Everything here is mechanical rule checks on Yahoo Finance data, not investment advice.
